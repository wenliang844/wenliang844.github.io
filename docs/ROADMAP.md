# CWLBlog 升级路线

更新日期：2026-08-10

## 已交付：第一阶段 P0

- 修复移动端目录遮挡和页面横向溢出，建立 390/768/1280px Playwright 验收。
- 未有完整英文正文前关闭文章英文切换，避免元数据英文、正文中文的混排。
- 移除浏览器内置 AI 密钥路径，保留本地能力和用户自有密钥模式。
- 支持 `draft: true` 构建隔离、IndexedDB 多草稿与自动保存。
- 文章列表改为摘要卡片，全文搜索迁移 Pagefind，RSS 输出完整正文。
- 建立分类、系列、连续阅读、修订信息、封面 alt 和响应式图片流水线。
- 增加知识资产页、关系图谱、可选隐私统计和公开内容 PWA 离线阅读。
- CI 增加 Playwright、Lighthouse、密钥扫描和依赖审计。
- CodeMirror 6 创作工作台已支持斜杠指令、快捷格式、实时诊断和预览同步；TypeScript 源码进入严格类型检查门禁。
- 已解析 WikiLink/普通内部链接，构建期阻止失效目标，并在文章页和知识图谱中生成反向链接与正文引用边。
- PWA 会同时检查请求路径和 referrer，确保编辑器页面加载的脚本也不会进入公共缓存；移动端不再显示遮挡正文的自动续读/下一篇浮层。
- 全站 CSP 已移除脚本侧 `unsafe-inline`：JSON-LD 使用逐页哈希、内联事件被禁用，Giscus 仅文章页，jsDelivr 仅工具箱，WASM 权限仅 Pagefind/MediaPipe 消费页。
- 公开路由已移除样式侧 `unsafe-inline`：阅读进度、画布、色块、弹窗和助手状态均改为 CSP 安全实现；仅 CodeMirror 编辑器保留路由级兼容例外。
- 公共页 `connect-src` 已按能力收敛到统计、订阅、固定 AI 预设与配置的 Worker Origin；任意 HTTPS 只保留在 Mini API Tester 所在的 `/tools/`。助手端点只读，历史密钥自动清除且 BYOK 不落盘。
- 单作者 GitHub OAuth、签名会话、CSRF/Origin 校验和 Git PR 发布 Worker 已实现；编辑器可创建 Draft/正式 PR 并显示预览地址。
- R2 图片上传已接入编辑器：短期签名许可、精确 Origin、类型/魔数/字节/像素复验、SHA-256、随机对象键和不可覆盖写入已实现。
- 相关文章已升级为构建期可解释推荐，综合正文引用、系列、专题、共同标签和发布时间接近度，不采集用户画像。
- 带引用知识问答已实现：稳定公开分块、关键词/向量混合召回、无证据兜底、SSE 来源、原子限流/预算和自动向量更新均已落地。
- 知识问答离线评测已进入 CI：问题集覆盖全部公开文章，Top-3 Recall 与离题拒答率门槛均为 90%，回答引用编号在输出前按实际来源范围校验。
- 文章集合与 `/post/` 路由已迁移到 Astro Content Collections；类型化 Schema、零诊断 `astro check`、限定目录同步和旧 HTML 等价性已纳入门禁。
- R2 可复用媒体库已接入编辑器：作者会话鉴权、固定前缀分页、最小元数据、筛选、封面复用和 Markdown 正文插入均已实现。
- R2 资源生命周期审计已具备 dry-run：构建产出已发布内容引用清单，作者接口按保护期分页识别孤立候选；自动删除保持关闭。
- 发布闭环已补齐 PR/CI 状态反馈：Worker 聚合 GitHub Check Runs，编辑器有限轮询并在终态停止。
- 知识资产页已增加内容健康看板：按月度可复现时钟计算 90/180 天维护状态、主题覆盖目标、链接/图谱孤立和可执行维护队列，并输出 `knowledge/health.json`。
- 每月内容备份与恢复演练已自动化：SHA-256 清单、隔离恢复、90 天 Artifact，以及配置凭据后可选的 R2 只读镜像均已进入独立工作流。

## 下一阶段：创作与发布闭环

- 补齐经人工确认的孤立资源清理和异步病毒扫描边界。
- 把公共布局、分类、系列、标签与知识页迁移为原生 Astro 组件，减少兼容模板与手写页面并存。

## 中期：知识与 AI

- 将公共布局、分类/系列/标签/知识页继续迁移为原生 Astro 组件；随后把浏览器 IIFE 迁移为 TypeScript/ES Modules 并按路由拆包。
- 每次新增内容同步扩充离线问题集，并用线上匿名结果分布复核无证据阈值后再扩大模型能力与上下文窗口。
- 继续用真实点击数据校准推荐权重；按看板维护队列补齐主题内容并扩充知识评测问题集。
- 建立统一日志与 Web Vitals 告警，并按季度对备份 Artifact 做独立 checkout 的完整构建恢复验收。

## 暂不建设

多租户、关注流、社区、会员中心、主题市场和插件市场暂不进入主线。当前优先级是内容质量、单作者发布效率、搜索可发现性和可信知识问答。
